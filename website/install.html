📖 Installation Guide

Install in Minutes

Get XBX 360 Homebrew Store running on your Aurora dashboard. Every step is clearly explained — no prior experience required.

⚠️
Early Access Beta
Public installation is not yet available. This page documents the installation process for when the store goes public. During Early Access, users receive a private build after requesting access.
📋 What You'll Need
🎮
Modded Console
JTAG or RGH modified Xbox 360
💿
Aurora Dashboard
Latest version installed
🌐
Internet Access
Wi-Fi or Ethernet on your 360
💾
Free Storage
~10 MB on HDD or USB
1 Download the Store Package

Download the latest XBX360Store.zip from the GitHub Releases page. This single file contains everything the store needs to run.

Screenshot
GitHub Releases page with XBX360Store.zip
Download URL
https://github.com/H3X-dev-xbox/xbx-360-homebrew-store/releases/latest
2 Extract the ZIP

Extract XBX360Store.zip using any ZIP tool — 7-Zip, WinRAR, or your phone's built-in file manager. You'll get a folder called XBX360Store/.

Screenshot
Extracted XBX360Store folder
3 Connect to Your Xbox 360

Transfer the XBX360Store folder to your console using one of these methods:

📶
FTP
Use FileZilla, WinSCP, or Aurora's FTP
🔌
USB Drive
FAT32-formatted USB stick
🌐
SMB Share
Via Aurora's network browser
4 Place It in the Right Folder

Copy the XBX360Store folder into Aurora's utility scripts directory. The exact path depends on where Aurora is installed:

Aurora Scripts Path
Hdd1:\Aurora\User\Scripts\Utility\XBX360Store\
💡
Tip
If you don't see a Utility folder, create one inside Scripts/. Aurora will find it automatically.
5 Launch the Store

On your Xbox 360, open Aurora → navigate to Scripts → tap XBX 360 Homebrew Store. The animated store interface will appear.

Screenshot
Aurora Scripts menu showing XBX 360 Homebrew Store
6 Install Homebrew

Browse categories, tap a game or app, and press Install. The store downloads from Archive.org and extracts to the correct folder — silently, automatically, and safely.

✅
Done
Your homebrew is now installed. Reload Aurora if needed, and it will appear in the appropriate category.
🔧
Troubleshooting
Store doesn't appear in Aurora: Make sure Aurora has been restarted and the folder is in the correct path.
Downloads fail: Check your console's internet connection and try again.
Extraction errors: Ensure your storage has enough free space.
