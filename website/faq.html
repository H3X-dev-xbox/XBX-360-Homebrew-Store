Questions & Answers

Everything you need to know about XBX 360 Homebrew Store, the beta, and how it all works.

🔍
⚖️ Legality & Safety
Yes. Only homebrew with licenses that permit redistribution is hosted. No commercial games, ROMs, BIOS files, or copyrighted content. Every item must have an open license (GPL, MIT, Apache, etc.) before it's added to the store.
No. The store uses plain HTTP downloads from Archive.org and GitHub. It never connects to Xbox Live, so Microsoft's servers don't see it. No ban risk from using the store.
No. Stealth servers are only needed for connecting to Xbox Live. The store is completely separate. Offline modded consoles work fine.
Open an issue on GitHub and content will be removed within 48 hours. We respect every developer's rights.
🎮 Hardware & Requirements
Yes. The store requires a JTAG or RGH modified Xbox 360 running the Aurora dashboard. Stock consoles cannot run homebrew and cannot use the store.
The store runs as an Aurora script, so it requires the Aurora dashboard. Aurora is the most actively maintained custom dashboard for modded Xbox 360 consoles. Support for other dashboards (like FSD) would require a standalone XEX build, which is on the long-term roadmap.
About 10 MB free for the store itself. Individual homebrew downloads vary — most games and apps are between 5 MB and 350 MB.
Yes, to download content. The store fetches its catalog from GitHub and downloads from Archive.org via plain HTTP. Wi-Fi or Ethernet both work.
💰 Pricing & Beta
Yes. Early Access is a small paid beta to control server bandwidth during testing. When the store goes public, it will be completely free for everyone — no subscription, no paywall, no hidden fees.
Three reasons: server bandwidth control (limited slots keep things stable), controlled testing (smaller groups give better bug reports), and supporter perk (early access thanks the people funding the beta). The fee disappears at public launch.
Open an issue on the GitHub repository titled Early Access Request. You'll get a private build once approved.
When the store is stable and tested enough. Follow the repo and watch Releases to be notified the moment it drops.
📦 Content
Four categories: Homebrew Games, Emulators, Applications, and Utilities. All must be legally redistributable.
Yes. Open an issue or pull request on the GitHub repository. Your homebrew must have a license that permits redistribution.
New content is added as it's submitted and verified. There's no fixed schedule — it depends on community contributions.
🛠️ Technical
On Archive.org. The GitHub repository holds only the catalog and metadata. When you tap Install, the store downloads from Archive.org in the background.
Open an issue on the GitHub repository. Include as much detail as possible.
