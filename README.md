## 🎮 What Is XBX 360 Homebrew Store?

**XBX 360 Homebrew Store** is a community-driven, fully open-source homebrew repository for the **Xbox 360**. It's designed to be the cleanest, fastest, and friendliest way to browse, download, and install **legally redistributable homebrew** — right from your console.

## 🚀 Early Access Beta — **Free at Public Launch**

**XBX 360 Homebrew Store is currently in a limited Early Access Beta.** Public installs are not open yet — but here's the deal:

> **💰 Paid now → 🆓 Free forever at public launch.**

The small early-access fee exists **only** to keep server bandwidth under control while the store is being finalized. It is **not** a subscription, **not** a paywall, and **not** a permanent cost. When the store goes public, **everyone gets full access for free.**

| | |
|---|---|
| **Current Status** | 🚀 Early Access Beta (Limited Slots) |
| **Early Access Cost** | 💰 Small one-time supporter fee |
| **Public Launch** | 🆓 **Completely free** |
| **Purpose of Fee** | 🖥️ Server & bandwidth overflow control |
| **Public Install** | ❌ Not available yet |
| **Expected Public Release** | 🔜 Coming Soon |

### Why Paid Early Access?
- 🖥️ **Server overflow protection** — limited slots keep bandwidth stable during testing
- 🧪 **Controlled testing** — a smaller group means better bug reports and faster fixes
- 💚 **Supporter perk** — early access is a thank-you to people helping fund the beta
- 🆓 **Free at launch** — the fee disappears the moment the store goes public

### What Beta Testers Get
- 🔑 Early access to the store before public release
- 🐛 Direct influence on features and fixes
- ⭐ Priority support
- 💚 A spot in the credits as a founding supporter

### What Everyone Gets at Launch
- ✅ Full free access to every category
- ✅ All legally redistributable homebrew
- ✅ The same store, same features — no paywall
- ✅ No subscription, no hidden fees, ever

- ⭐ **Star this repo** to be notified the moment the public release drops.
- 👀 **Watch the repo** (Releases only) for beta announcements.
- 📩 **Early access inquiries:** open an issue titled `Early Access Request`.

## ⚖️ Legal

**XBX 360 Homebrew Store is an unofficial fan project. It is not affiliated with, endorsed by, or connected to Microsoft Corporation in any way.**

- ✅ **Only** legally redistributable homebrew is hosted.
- ✅ Content must have a license permitting redistribution (GPL, MIT, Apache, etc.).
- ❌ **No** commercial games, ROMs, BIOS files, or copyrighted assets.
- ❌ **No** piracy tools, key generators, or DRM circumvention software.
