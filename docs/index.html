FAQ

Frequently Asked

Quick answers to the most common questions.

Yes. The store requires a JTAG or RGH modified Xbox 360 running the Aurora dashboard. Stock (unmodified) consoles cannot run homebrew and cannot use the store.
No. Stealth servers are only needed for connecting to Xbox Live. The store uses plain HTTP downloads from Archive.org and GitHub — completely separate from Xbox Live. No ban risk from using the store.
Yes. Early Access is a small paid beta to control server bandwidth during testing. When the store goes public, it will be completely free for everyone — no subscription, no paywall, no hidden fees.
The store runs as an Aurora script, so it requires the Aurora dashboard. Aurora is the most actively maintained custom dashboard for modded Xbox 360 consoles. Support for other dashboards would require a standalone XEX build, which is on the long-term roadmap.
Open an issue on the GitHub repository. All reports help make the store better for everyone. You can also join the discussion in the repository's Issues tab.
